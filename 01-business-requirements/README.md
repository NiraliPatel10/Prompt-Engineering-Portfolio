# Online Shopping Application – Business Analysis Case Study

## Project Overview
This repository presents a **Business Analysis case study** for an Online Shopping Application.  
The objective of this project is to demonstrate how high-level stakeholder ideas are translated into **structured business requirements, functional requirements, user stories, and process diagrams** using industry-standard BA practices.

The solution supports core e-commerce functionality including user account management, product browsing, shopping cart management, checkout with multiple payment options, and automated email notifications.

---

## Business Objectives
- Enable digital product sales through an online platform
- Improve customer accessibility and user experience
- Support secure and scalable online transactions
- Provide timely communication to customers regarding order status

---

## Artefacts Included

### 1. Business Requirements
- Clear articulation of business needs and goals
- Alignment with organisational objectives
- Scope definition and assumptions

### 2. Functional Requirements
- Detailed system behaviours and capabilities
- Coverage of account management, product browsing, cart management, checkout, and notifications

### 3. User Stories
- Agile-style user stories written from the customer perspective
- Supports backlog creation and sprint planning
- Includes acceptance criteria and priorities

### 4. Non-Functional Requirements
- Performance
- Security (PCI-DSS compliance, encryption)
- Availability and reliability
- Usability and accessibility (WCAG)
- Scalability

### 5. Acceptance Criteria
- Defined using **Given / When / Then** format
- Ensures testability and clear validation of requirements

---

## Process & Design Artefacts

### Wireframe-Level Functional Flows
- User Registration
- Browse and Add to Cart
- Checkout and Payment

These flows describe **screen-level interactions** and support UX and development handoff.

### BPMN Diagram
- End-to-end **Order Placement process**
- Includes decision gateways for checkout and payment success/failure
- Demonstrates process modelling skills used in enterprise environments

### UML Use Case Diagram
- Actors: Customer, Payment Gateway, Email Service
- Use cases covering the full customer journey
- Clearly illustrates system interactions and boundaries
