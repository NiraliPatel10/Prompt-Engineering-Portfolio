# Executive Summary Generator

## Project Overview
This project demonstrates how prompt engineering can be used to convert detailed business reports into concise, executive-ready summaries.

## Objective
To support executive decision-making by delivering clear, structured insights from complex analytical reports.

## Approach
A structured prompt was designed to guide a large language model to:
- Extract key objectives and findings
- Identify risks and challenges
- Provide actionable recommendations
- Maintain executive-level language and clarity

## Business Value
- Saves executive time by summarising complex reports
- Improves clarity and consistency in leadership communications
- Supports faster, data-driven decision-making

## Skills Demonstrated
- Prompt Engineering
- Business Analysis
- Executive Communication
- Insight Synthesis
